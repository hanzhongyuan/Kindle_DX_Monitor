打开 KindlePaperwhite2MessageBoard.exe，每行写一项，点“推送待办”；每批最多 200 项、每项最多 300 字，不受封面行数或字号限制。

Paperwhite 2 专用：KindlePaperwhite2MessageBoard.exe
支持可调排版的休眠封面及 KOReader 待办文字推送，不做扩展显示器；适用固件 5.12.2.2。
首次先读 docs/PAPERWHITE2_MESSAGEBOARD.zh-CN.md，完成设备越狱及 linkss 屏保插件配置。
USB方式：接数据线，确认Kindle存储盘出现 → 选择行数、字体和字号，编辑或粘贴文字 → 预览 → USB发送 → 等待完成 → 安全弹出并拔线。
首次启用自动重载后，按提示完整重启一次；以后拔线约十秒后会重新载入界面，再短按电源显示封面。
无线方式需先按指南完成一次设备配对，以后：手动唤醒Kindle → 电脑和Kindle连同一Wi-Fi、拔掉USB → 预览 → 无线发送 → 等书库回来 → 短按电源显示封面。
窗口里的“Kindle IP 地址”会记住上次设置；地址变了，修改后点“保存地址”。
程序不提供远程唤醒、后台常在线或外网发送。
“USB恢复封面”和“无线恢复封面”均还原程序接管前的屏保图片，不卸载插件；按所选方式连接后使用。
无线配对记录丢失时，可用USB运行pw2-wireless-setup.py重新配对，不需重新越狱；原封面备份记录仍需保留。
PW2 草稿保存在 runtime/paperwhite2/messageboard-draft.txt，与 DX 分开。
可选 1–30 行、本机字体和 12–120 px 正文字号，默认十行、微软雅黑。
可选纵向或横向，默认纵向；横向预览为 1024×758，发送后把 Kindle 顺时针转 90° 阅读。
“自动缩小字号”默认开启，按行宽和行高适配；关闭后按指定字号显示，放不下时需调整。
减少行数不会删掉文字；超过所选行数时，增加行数或调整内容后才能预览和发送。
排版设置保存在 runtime/paperwhite2/messageboard-layout.json，下次打开继续使用；图片仍为 758×1024。
保留整个 runtime/paperwhite2，以及 Kindle 的 linkss/pw2-messageboard-backup。
本次无线代码更新未进行实际发送与恢复测试。电脑提示完成后，还需在Kindle上确认显示结果。

一、Kindle 留言板：KindleMessageBoard.exe
双击直接进入留言编辑窗口，不需要先打开显示器程序。
1. 唤醒 Kindle，接上 USB 数据线，保持 USB 网络模式。
2. 选择行数、字体和字号，在一个多行文本框里编辑或粘贴文字，每行一条。
3. 点击“预览”，再点“发送到 Kindle”，等待完成提示。
4. 成功后可以关闭程序、拔线，文字保留在 Kindle 的休眠封面。

支持 Ctrl+A 全选、Ctrl+C 复制、Ctrl+V 粘贴整段内容，Enter 换行。
与 PW2 一样可选 1–30 行、本机字体和 12–120 px 正文字号，默认十行、微软雅黑。
可选纵向或横向，默认纵向；横向预览为 1200×824，发送后把 Kindle 顺时针转 90° 阅读。
“自动缩小字号”默认开启，按行宽和行高适配；关闭后按指定字号显示，放不下时需调整。
超过所选行数会保留全部文字，增加行数或调整内容后再预览和发送。
编辑自动保存在本机 runtime/messageboard-draft.txt，未发送的修改也会保存。
排版设置保存在 runtime/messageboard-layout.json，与 PW2 分开；图片仍为 824×1200。
下次打开继续编辑；旧版 JSON 草稿兼容读取。
“恢复原休眠封面”可以撤销留言板；关闭窗口只保存草稿并退出。
Kindle 完整重启会恢复原封面，需要重新发送；普通休眠和拔线可保留。
只用留言板无需安装虚拟显示驱动、TightVNC、PowerShell 7 或 Kindle VNC 客户端。
首次仍需按新手指南准备 USBNetwork、Python 和可信主机公钥。

二、Kindle 显示器：KindleDisplay.exe
1. Kindle 保持 USB 网络模式，接上数据线。
2. 双击 KindleDisplay.exe，选择方向，点击“连接”。
3. Windows 保持“扩展这些显示器”，将窗口拖到 Kindle 对应的屏幕。

连接：启用专用扩展屏，开始显示。
断开连接：停止显示，恢复 Kindle 阅读界面，保留电脑控制窗口。
刷新：重新加载当前画面。
应用方向：应用下拉框所选的 0°、90°、180° 或 270°，成功后记住选择。
退出：断开连接并关闭窗口；右上角关闭按钮作用相同。
最小化：继续显示，程序留在任务栏。

切换方向可能需要十几秒，并会闪屏、短暂回到 Home。
横屏朝向相反时，选择另一个横屏方向。
若 Windows 出现合并的 2|3 屏幕，改成“扩展 2 和 3 上的桌面”并保留更改。
屏幕编号以本机实际显示为准。
USB 暂时断开会自动重试；电脑睡眠或关机时无法继续更新画面。
停止显示请在电脑中断开；只按 Kindle Home 会触发客户端重连。
墨水屏适合静态文字和文档，Windows 的 60 Hz 不代表墨水屏有 60 fps。

三、在两种用途之间切换
显示器切到留言板：先在 KindleDisplay.exe 点击“断开连接”，再到 KindleMessageBoard.exe 发送留言。
留言板不会自动停止显示器，两边不要同时向 Kindle 发送画面。
留言板切到显示器：唤醒 Kindle，接回 USB 网络，在 KindleDisplay.exe 点击“连接”。
两个程序都可以最小化到任务栏，分别打开、分别退出。
另一个程序正在操作设备时会提示等待；显示器连接中或重连中，也需先断开再发送留言。

四、重启后恢复 USB 网络
Kindle 重启后若变为存储盘：安全弹出并拔线，按 Home，直接用实体键盘唤出搜索栏。
逐条输入并提交：
;debugOn
`usbNetwork
;debugOff
然后重新插线。第二条以反引号开头；命令区分大小写。
这是一条切换命令，已经处于 USB 网络模式时不要反复执行。

五、保存与更新
私人留言和本机运行记录不随仓库发布。
升级前关闭两个程序并备份旧项目文件夹，将新版内容覆盖到旧目录。
保留整个 runtime、.venv 和本机配置；不要删除旧目录后重新下载。
特别保留 messageboard-draft.txt、messageboard-layout.json、messageboard-state.json 和 kindle_known_hosts。
扩展屏用户还需保留 virtual-display-install.json 与 scripts/display-baseline.json。
新电脑需要重新创建 Python 环境，具体见新手指南。
